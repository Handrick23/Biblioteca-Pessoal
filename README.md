# 📚 Sistema de Biblioteca com PHP & MySQL

---

## 📝 Descrição

Este projeto foi desenvolvido em **PHP** com integração a um banco de dados **MySQL**, com o objetivo de criar um **Sistema de Biblioteca** simples e funcional, permitindo o **gerenciamento de livros** por meio de operações CRUD.

A aplicação ilustra, de forma prática, como **integrar o PHP com um banco de dados relacional**, manipulando registros e exibindo resultados de forma dinâmica.  
É uma excelente base para quem deseja aprender a desenvolver aplicações web completas utilizando **frontend (HTML + CSS)** e **backend (PHP + SQL)**.

---

## ⚙️ Funcionalidades

- ➕ **Adicionar livros** ao acervo  
- 📝 **Editar informações** de um livro existente  
- ❌ **Excluir livros** do sistema  
- 📖 **Visualizar a lista completa** de livros cadastrados  
- 🔍 **Filtrar livros** por título, autor ou categoria  
- 🔄 **Atualizações automáticas** após cada operação no banco de dados
